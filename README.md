# 铁塔换电支付系统静态演示

本项目使用 HTML、CSS 和原生 JavaScript 展示铁塔换电分期办理与账单缴费流程，适合用于页面预览、流程演示和沟通。页面针对手机屏幕设计，也可在桌面浏览器中查看。

## 本地预览

直接双击打开 `src/index.html` 即可预览，无需安装依赖、启动服务器或执行构建。

## 演示流程

首页提供“签约”和“缴费”两个入口，也可以通过“单页预览”单独打开任意页面。

- **签约**：铁塔收银台 → 套餐详情 → 订单确认 → 支付宝签约 → 办理成功。订单确认页可打开服务协议，勾选同意后继续。
- **缴费**：确认缴费 → 缴费成功。点击“立即支付”后直接展示结果。

页面使用示例订单、套餐和账单数据。铁塔、支付宝相关页面均为静态演示，不连接业务接口，也不会实际发起签约、扣款或缴费；展示的金额、日期和状态不代表真实交易。

## 目录说明

```text
src/
├── index.html                    # 首页：流程入口和单页预览
├── pages/
│   ├── cashier.html              # 铁塔收银台
│   ├── tower-cashier.html        # 铁塔套餐详情
│   ├── order-confirm.html        # 订单确认和协议
│   ├── alipay-periodic.html      # 支付宝签约页面
│   ├── order-result.html         # 办理结果
│   ├── bill-detail.html          # 确认缴费
│   └── bill-result.html          # 缴费结果
└── assets/
    ├── css/                      # 页面样式
    ├── js/                       # 示例数据、交互和服务协议内容
    └── icons/                    # 页面图标及其许可证
```
