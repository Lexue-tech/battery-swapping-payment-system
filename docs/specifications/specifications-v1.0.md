# 功能规格文档

## 项目概述
铁塔换电支付系统 - 先享后付签约流程Demo

## 变更历史
| 版本 | 日期 | 作者 | 变更描述 |
|------|------|------|----------|
| 1.0  | 2026-04-09 |  | 初始版本，纯前端Demo |

## 特别说明
**本项目为纯前端Demo**
- 无后端接口调用
- 所有数据仅在页面间传递（URL参数、LocalStorage等）
- 页面跳转完全由前端控制
- 用于演示用户交互和页面跳转流程

## 功能模块

### 1. 铁塔收银台 - 新增先享后付套餐
### 2. ISV 订单确认页 - 确认订单信息
### 3. ISV 订单确认页 - 确认告知书
### 4. ISV 订单确认页 - 人脸识别 + 活体认证
### 5. 支付宝收银台 - 完成签约
### 6. 铁塔订单页 - 签约成功

---

### 1. 铁塔收银台 - 新增先享后付套餐

#### 1.1 模块描述
展示先享后付套餐信息，是整个签约流程的入口页面。

#### 1.2 页面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 套餐名称 | 文本 | 显示"先享后付套餐" |
| 套餐价格 | 文本 | 显示价格信息 |
| 立即购买按钮 | 按钮 | 点击跳转至订单确认页 |

#### 1.3 交互流程
```
用户进入页面 → 查看套餐信息 → 点击"立即购买" → 跳转至订单确认页(携带套餐信息)
```

#### 1.4 数据传递
通过URL参数传递：`/order-confirm.html?package=先享后付&price=xxx`

#### 1.5 验收标准
- [ ] 页面完整显示套餐信息
- [ ] 点击"立即购买"正确跳转

---

### 2. ISV 订单确认页 - 确认订单信息

#### 2.1 模块描述
展示用户即将购买的订单详情，用户确认后进入签约流程。

#### 2.2 页面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 订单详情区域 | 文本 | 显示套餐名称、价格等信息 |
| 去签约按钮 | 按钮 | 点击跳转至告知书确认页 |

#### 2.3 交互流程
```
接收套餐信息 → 显示订单详情 → 点击"去签约" → 跳转至告知书确认页
```

#### 2.4 数据传递
接收URL参数，传递给下一页

#### 2.5 验收标准
- [ ] 正确显示订单详情
- [ ] 点击"去签约"正确跳转

#### 3.1 模块描述

| 元素 | 类型 | 说明 |
|------|------|------|
| 告知书内容 | 文本区域 | 展示告知书正文 |
| 完成按钮 | 按钮 | 点击跳转至人脸识别页 |

#### 3.3 交互流程


#### 3.5 验收标准
- [ ] 完整显示告知书内容
- [ ] 点击"完成"正确跳转

### 4. ISV 订单确认页 - 人脸识别 + 活体认证

#### 4.1 模块描述
模拟支付宝人脸识别认证流程（Demo中模拟实现）。

#### 4.2 页面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 人脸识别区域 | 图像/动画 | 模拟人脸识别界面 |
| 开始认证按钮 | 按钮 | 点击开始模拟认证 |

#### 4.3 交互流程
```
进入页面 → 点击"开始认证" → 显示模拟认证动画(2-3秒) → 自动跳转至支付宝签约页
```

#### 4.4 模拟说明
- Demo中不调用真实支付宝能力
- 使用CSS动画模拟认证过程
- 认证完成后自动跳转

#### 4.5 验收标准
- [ ] 显示人脸识别界面
- [ ] 点击后有认证动画
- [ ] 动画结束后自动跳转

### 5. 支付宝收银台 - 完成签约

#### 5.1 模块描述
模拟支付宝签约确认页面（Demo中模拟实现）。

#### 5.2 页面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 签约确认信息 | 文本 | 显示待签约服务信息 |
| 确认签约按钮 | 按钮 | 点击确认签约 |
| 回到商家按钮 | 按钮 | 签约成功后显示，点击返回订单页 |

#### 5.3 交互流程
```
进入页面 → 显示签约信息 → 点击"确认签约" → 显示成功状态 → 显示"回到商家"按钮 → 点击跳转至订单成功页
```

#### 5.4 模拟说明
- Demo中点击确认后直接显示成功
- 无真实支付宝签约调用
- "回到商家"按钮在签约成功后显示

#### 5.5 验收标准
- [ ] 显示签约信息
- [ ] 点击后显示签约成功
- [ ] 显示"回到商家"按钮

### 6. 铁塔订单页 - 签约成功

#### 6.1 模块描述
展示签约成功结果页面，是整个签约流程的终点。

#### 6.2 页面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 成功提示 | 文本 | 显示"签约成功" |
| 订单信息 | 文本 | 显示订单详情 |
| 返回首页按钮 | 按钮 | 点击返回铁塔收银台 |

#### 6.3 交互流程
```
进入页面 → 显示签约成功信息 → 点击"返回首页" → 跳转至铁塔收银台(重新开始)
```

#### 6.4 数据存储
签约结果可存储在LocalStorage中用于展示

#### 6.5 验收标准
- [ ] 显示签约成功信息
- [ ] 点击"返回首页"跳转至收银台

## 模块间依赖关系
```
[铁塔收银台] ──URL参数──> [ISV订单确认-信息] ──Session──> [ISV订单确认-告知书]
      ▲                                                            │
      │                                                            │
      └────────────────── [铁塔订单页] <───URL参数─────────────────┘
```

## 前端路由方案
| 页面 | 文件名 | URL参数 |
|------|--------|---------|
| 铁塔收银台 | index.html | - |
| ISV订单确认-信息 | order-confirm.html | package, price |
| ISV订单确认-告知书 | disclosure.html | - |
| ISV订单确认-人脸识别 | face-recognition.html | - |
| 支付宝签约 | alipay-sign.html | - |
| 铁塔订单页 | order-success.html | package, price, signTime |
